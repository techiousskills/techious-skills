# Techious Skills Website

A presentation-ready, responsive static website for Techious Skills.

## Files
- `index.html` — complete one-page website
- `style.css` — responsive styling
- `script.js` — mobile navigation, registration form and WhatsApp handoff
- `images/` — local SVG visual assets and logo mark

## GitHub Pages
Upload all files while preserving the `images` folder. Set GitHub Pages to deploy from the branch/folder containing `index.html`.

The registration form opens WhatsApp to **0912 381 0160** with the learner's enquiry pre-filled.
