# Techious Skills Landing Page

A simple one-page website for Techious Skills (Computer Appreciation Training).

## Files
- index.html
- style.css
- script.js
- images/logo-placeholder.svg
- images/hero-placeholder.svg

## Host on GitHub Pages
1. Create a public GitHub repository named `techious-skills`.
2. Upload all files.
3. Go to **Settings → Pages**.
4. Under **Deploy from a branch**, choose `main` and `/root`.
5. Save.

Your website will be available at:
`https://YOUR-GITHUB-USERNAME.github.io/techious-skills`
